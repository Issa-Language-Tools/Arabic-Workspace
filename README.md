# Purpose

This is my language learning workspace for Arabic Learning

## Requirements

- Qt 6 (Widgets)
- SQLite3
- CMake 3.16+

## Project Organization

`src/`          - Application Logic & Source Code
`structs/`      - Global Custom Data Types
`migrations/`   - SQL migration files
`build/`        - Autogenerated Build Files
`scripts/`      - Developer utility scripts (e.g. migration generator)
`words.db`      - SQLite database (created on first run)

## Build & Run

To build the app run `make all`; to build and launch run `make run` (`build/release/workspace`).

## Migrations

To create a new migration file, run `scripts/migrate` and supply the file name as the first argument.

> [!NOTE]
> A new migration file will be created in the proper naming convention.
