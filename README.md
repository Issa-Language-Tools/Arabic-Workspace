# Purpose

This is my language learning workspace for Arabic Learning

## Project Organization

`src/`              - Application Logic & Src Code
`structs/`          - Global Custom Data Types  
`migrations/`       - SQL migration files
`build/`            - Autogenerated Build Files
`bin/`              - Scripts to run

To build the app run `make all` and you can find the application under `/build/release/workspace`

To build a new migration file - run `/bin/migrate` and supply name of the file as the first argument. 

> ![note] A new migration file will be created in the proper naming convention
